FAQ

Common questions about Oak DayZ.

How do I get access?

Create an account, redeem a key on Account (or buy a plan when checkout is live), then download the launcher.

Where is the client DLL?

You don’t download it from the website. The launcher fetches the latest client from the API when you inject.

HWID locked to another PC?

Open a Support ticket with category HWID reset. Self-reset may be limited by cooldown; staff can reset when needed.

Account banned?

Login will show the ban reason. Open a ticket only if you believe it was a mistake.

Forgot password?

Use Forgot password — we’ll email a reset link.
